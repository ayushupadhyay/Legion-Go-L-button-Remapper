# Preview release checklist

Completed:

- [x] Prototype physically opens Game Bar from Legion L on one Go S.
- [x] Prototype sign-in task starts and connects to the controller.
- [x] Source contains no personal paths, MagicPods or third-party runtime binaries.
- [x] Packaged C# source builds on Windows x64.
- [x] PowerShell scripts pass syntax validation.

Required before a stable release:

- [ ] Clean-user installation without the prototype listener.
- [ ] Cold boot directly into Xbox mode; verify one listener instance.
- [ ] Manual Space shortcut works; document already-running Space behaviour.
- [ ] Legion R and Lenovo power/fan controls still work.
- [ ] Launcher filename change and exact restoration on a stock signed installation.
- [ ] Restoration refuses to overwrite a launcher recreated by Lenovo updates.
- [ ] Disconnect/reconnect, sleep/resume and uninstall.
- [ ] Confirm repository ownership, name, license and attribution before publishing.

Do not claim support for Go 1, Go 2, D-input or all firmware revisions.
